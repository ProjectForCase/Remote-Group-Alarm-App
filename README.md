# Remote Group Alarm App
# 遠端團體鬧鐘 App

A mobile app that allows users to create and manage group alarms remotely, enabling shared wake-up reminders and interactive alarm participation.
可建立多人共享鬧鐘，讓成員進行遠端互動與提醒，適合用於團體行程、讀書會、活動集合提醒等情境。

## Features
- Create group alarms
- Invite members to join alarm groups
- Remote alarm interaction
- Shared reminder notifications
- Android mobile interface

## Tech Stack
- Android
- Kotlin / Java
- Firebase / Database
